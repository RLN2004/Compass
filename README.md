# Compass Lite

A simple offline Android compass using the device rotation-vector sensor. It requires no internet connection and requests no permissions.

## Build APK

Pushes to `main` trigger the GitHub Actions workflow. Open the repository's **Actions** tab, select the latest successful run, and download the `CompassLite-debug-apk` artifact. Extract it to get `app-debug.apk`.

If the compass heading is unstable, calibrate the phone by moving it in a figure-eight and keep it away from magnets or magnetic phone cases.
